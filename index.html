Featured project

RCP 5G Cloud-Native Deployment Automation

A CI/CD pipeline for 5G RCP microservices that automates build, test and deployment, so releases ship faster and stay stable. Every commit moves through these six stages.

  1. 01

    Source

    A Jenkins multibranch pipeline picks up every branch.

    Git/GitHub · Jenkins
  2. 02

    Build

    Maven compiles and packages the service.

    Maven
  3. 03

    Quality gate

    SonarQube checks the code before it moves on.

    SonarQube
  4. 04

    Artifact

    Build outputs are stored for release.

    Nexus
  5. 05

    Image

    Docker images are pushed to a private registry.

    Docker · Nexus / Docker Hub
  6. 06

    Deploy

    Services roll out to Kubernetes from YAML files.

    Kubernetes
UnderneathTerraform provisions the infrastructure the cluster runs on.
AlongsidePrometheus, Grafana and Splunk watch the services in production.
